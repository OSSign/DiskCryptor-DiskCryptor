# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [DiskCryptor/DiskCryptor](https://github.com/DiskCryptor/DiskCryptor/) project.

## Where are the signed binaries published?
The signed drivers are published by the author on [DiskCryptor/DiskCryptor](https://github.com/DiskCryptor/DiskCryptor).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/DiskCryptor-DiskCryptor/actions).
